# Pokémon Battle Game

A console-based Pokémon battle and catching game developed in Java.

## Project Overview

This project allows users to register, log in, select a starter Pokémon,
battle computer-controlled opponents, catch Pokémon and view battle scores
on a leaderboard.

## Features

- Player registration and login
- Starter Pokémon selection
- Turn-based battle system
- Elemental Pokémon types
- Multiple move skills
- Pokémon catching system
- Six-Pokémon inventory limit
- Battle score calculation
- Top-five leaderboard
- Input validation

## Technologies Used

- Java
- Object-oriented programming
- ArrayList
- HashMap
- Inheritance
- Polymorphism
- Exception handling
- Random number generation
